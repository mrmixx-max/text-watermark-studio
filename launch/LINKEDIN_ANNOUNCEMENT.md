🚀 **Announcing Text Watermark Studio v2.0.0 — Open Source, 100% Local**

Today we're releasing a complete, taxonomy-driven watermarking laboratory that runs entirely on your machine. No cloud. No telemetry. Just verifiable forensics.

**What it does:**
Text Watermark Studio detects, removes, embeds, and verifies watermarks in AI-generated text. It combines unicode stego detection, statistical KGW analysis, e-process testing, and quantum-safe signed forensic reports — all in one open-source toolkit.

**Why it matters:**
As AI-generated content becomes ubiquitous, the ability to prove — not just claim — whether text carries a watermark is critical for:
- **Journalists** verifying source authenticity
- **Researchers** measuring detection efficacy
- **Legal teams** producing signed forensic findings
- **Developers** building on a local-first, auditable stack

**Key features in v2.0.0:**
🔬 KGW statistical detection with ΔZ measurement
📝 Signed forensic reports (HMAC-SHA256 or ML-DSA FIPS 204)
🧹 Best-effort watermark removal with honest reporting
🖥️ Desktop app (PySide6) + 25-action TUI + FastAPI server
🐳 Docker support, CI/CD, Python 3.10–3.12

**Install:** `pip install text-watermark-studio`
**Repository:** github.com/mrmixx-max/text-watermark-studio
**License:** MIT

We built this because honest detection requires honest tools — tools that say what they can and cannot do. The result is a lab, not a black box.
